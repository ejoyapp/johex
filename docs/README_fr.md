# JoHex — Studio d'Analyse Binaire

## 🚀 Découvrez JoHex : Le Studio d'Analyse Binaire Nouvelle Génération
JoHex est un Studio d'Analyse Binaire professionnel conçu pour les rétro-ingénieurs, les chercheurs en sécurité, les développeurs de firmwares et les experts en criminalistique numérique.

Contrairement aux éditeurs hexadécimaux traditionnels qui ne font qu'afficher des octets bruts, JoHex transforme les données binaires en un environnement d'analyse interactif combinant :
- Édition hexadécimale avancée
- Analyse de structures binaires
- Flux de travail de rétro-ingénierie
- Investigation de disques bruts
- Analyse de la mémoire des processus
- Automatisation Python extensible

Construit avec une architecture C++ native et des interfaces système Win32/POSIX directes, JoHex offre un accès bas niveau ultra-performant avec une surcharge minimale.

## 🔥 Fonctionnalités Principales

### 🧬 Inspection Binaire Intelligente
Analysez des formats binaires complexes au-delà des simples vues hexadécimales.
**Fonctionnalités :**
- Visualisation de la structure binaire
- Navigation basée sur les offsets
- Interprétation des données
- Modèles binaires personnalisés
- Exploration de formats de fichiers
- Comparaison au niveau de l'octet

### 🕵️ Boîte à Outils de Rétro-Ingénierie
Conçu pour la recherche binaire approfondie.
**Capacités :**
- Inspection de la mémoire des processus en direct
- Analyse des régions de mémoire
- Modification de la mémoire à l'exécution
- Investigation d'exécutables
- Découverte de modèles binaires

### 💽 Analyse Avancée de Disques et de Stockage
Accès bas niveau direct pour les flux de travail de criminalistique.
**Analysez :**
- Disques physiques
- Secteurs bruts
- Structures MBR/GPT
- Tables de partitions
- Espace non alloué
- Images de disques

### ⚡ Moteur de Recherche Haute Performance
Recherchez efficacement dans des téraoctets de données binaires.
**Pris en charge :**
- Signatures d'octets exactes
- Modèles hexadécimaux
- Caractères génériques (Wildcards)
- Expressions régulières
- Recherche en streaming
- Pagination de fichiers volumineux

### 🐍 Automatisation Python & Système de Plugins
Étendez JoHex avec Python 3.12.
**Créez :**
- Analyseurs personnalisés
- Analyseurs syntaxiques binaires
- Scripts d'automatisation
- Outils de criminalistique
- Flux de travail d'analyse assistés par l'IA

Accédez à des milliers de bibliothèques Python directement dans JoHex.
