# JoHex — 二進制分析工作室

## 🚀 探索 JoHex：新一代二進制分析工作室
JoHex 是一款專為逆向工程師、安全研究人員、韌體開發者和數碼鑑證專家設計的專業二進制分析工作室。

與僅顯示原始位元組的傳統十六進制編輯器不同，JoHex 將二進制數據轉化為互動式分析環境，結合了以下功能：
- 高級十六進制編輯
- 二進制結構分析
- 逆向工程工作流
- 原始磁碟鑑證
- 進程記憶體分析
- 可擴展的 Python 自動化

JoHex 採用原生 C++ 架構和直接的 Win32/POSIX 系統介面構建，提供極低開銷的高性能底層存取。

## 🔥 核心功能

### 🧬 智能二進制審查
在原始十六進制視圖之外，分析複雜的二進制格式。
**特性：**
- 二進制結構視覺化
- 基於偏移量的導航
- 數據解釋
- 自定義二進制模板
- 檔案格式探索
- 位元組級別對比

### 🕵️ 逆向工程工具包
專為深度二進制研究而設計。
**能力：**
- 實時進程記憶體審查
- 記憶體區域分析
- 運行時記憶體修改
- 執行檔調查
- 二進制模式發現

### 💽 高級磁碟與儲存分析
直接的底層存取，助力數碼鑑證工作流。
**支持分析：**
- 物理磁碟
- 原始磁區
- MBR/GPT 結構
- 分割表
- 未分配空間
- 磁碟映像

### ⚡ 高性能搜尋引擎
高效搜尋 TB 級的二進制數據。
**支持：**
- 精確位元組簽章
- 十六進制模式
- 通配符
- 正規表達式
- 串流搜尋
- 大檔案分頁

### 🐍 Python 自動化與插件系統
使用 Python 3.12 擴展 JoHex。
**創建：**
- 自定義分析器
- 二進制解析器
- 自動化腳本
- 鑑證工具
- AI 輔助分析工作流

直接在 JoHex 內部存取成千上萬的 Python 庫。
