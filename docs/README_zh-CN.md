# JoHex — 二进制分析工作室

## 🚀 探索 JoHex：新一代二进制分析工作室
JoHex 是一款专为逆向工程师、安全研究人员、固件开发者和数字取证专家设计的专业二进制分析工作室。

与仅显示原始字节的传统十六进制编辑器不同，JoHex 将二进制数据转化为交互式分析环境，结合了以下功能：
- 高级十六进制编辑
- 二进制结构分析
- 逆向工程工作流
- 原始磁盘取证
- 进程内存分析
- 可扩展的 Python 自动化

JoHex 采用原生 C++ 架构和直接的 Win32/POSIX 系统接口构建，提供极低开销的高性能底层访问。

## 🔥 核心功能

### 🧬 智能二进制审查
在原始十六进制视图之外，分析复杂的二进制格式。
**特性：**
- 二进制结构可视化
- 基于偏移量的导航
- 数据解释
- 自定义二进制模板
- 文件格式探索
- 字节级对比

### 🕵️ 逆向工程工具包
专为深度二进制研究而设计。
**能力：**
- 实时进程内存审查
- 内存区域分析
- 运行时内存修改
- 可执行文件调查
- 二进制模式发现

### 💽 高级磁盘与存储分析
直接的底层访问，助力数字取证工作流。
**支持分析：**
- 物理磁盘
- 原始扇区
- MBR/GPT 结构
- 分区表
- 未分配空间
- 磁盘映像

### ⚡ 高性能搜索引擎
高效搜索 TB 级的二进制数据。
**支持：**
- 精确字节签名
- 十六进制模式
- 通配符
- 正则表达式
- 流式搜索
- 大文件分页

### 🐍 Python 自动化与插件系统
使用 Python 3.12 扩展 JoHex。
**创建：**
- 自定义分析器

- AI 辅助分析工作流

直接在 JoHex 内部访问成千上万的 Python 库。
